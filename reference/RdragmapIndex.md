# An Rdragmap reference index

A reference index produced by
[`rdragmap_build_index()`](https://rgenomicsetl.github.io/Rdragmap/reference/rdragmap_build_index.md)
or validated by
[`rdragmap_index()`](https://rgenomicsetl.github.io/Rdragmap/reference/rdragmap_index.md).
It records an absolute directory containing the native DRAGMAP v8
reference, compressed hash table, and binary configuration.

## Usage

``` r
RdragmapIndex(directory = character(0))
```

## Arguments

- directory:

  Absolute reference-index directory.
